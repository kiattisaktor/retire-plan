# EGAT Retirement Blueprint (แผนการเงินเพื่อการเกษียณ 25 ล้านบาท)

เว็บแอปพลิเคชัน Interactive Dashboard และแบบจำลองกระแสเงินสดเพื่อการเกษียณอายุ 25.00 ล้านบาท สำหรับพนักงาน กฟผ. (ช่วงอายุ 38 – 60 ปี)

### จุดเด่นของระบบ
1. **ภาพรวม 6 ตะกร้าสินทรัพย์ (25.00M):** พร้อมผลตอบแทนและกระแสเงินสดเฉลี่ย 54,004 บาท/เดือน
2. **ระบบท่อกระแสเงินสดคู่ (Dual Pipelines):**
   * **ท่อที่ 1 คุณแม่ (แยกบัญชี 100%):** ปันผลหุ้น สอ.กฟผ. 4M @ 4.5% = 15,000 บาท/เดือน จนถึงอายุ 98 ปี
   * **ท่อที่ 2 ส่วนตัว:** 50,038 บาท/เดือน (งบกินอยู่ 35k + Surplus ค่ารักษาพยาบาล 15,038 ฿)
3. **แผนสะสมรายปี 23 ปี (อายุ 38-60 ปี):** PVD 15%, หุ้นสหกรณ์, RMF, ประกันเดิม 3 ฉบับ, บำนาญใหม่จากโบนัส
4. **แผน Drawdown เงินต้น 3 ระยะ:** ปกป้องเงินต้นช่วง 60-70 ปี และรองรับ Medical Inflation ในวัยเกษียณ
5. **Interactive Calculator:** จำลองปรับเปลี่ยนตัวแปรงบกินอยู่, ผลตอบแทน %, และเงินบำนาญแบบ Real-time
